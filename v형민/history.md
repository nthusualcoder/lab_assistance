# 프로젝트 작업 히스토리 - 형민 버전 (history.md)

본 문서는 실험 보조 계산기 - 형민 버전 어플리케이션의 개발 과정과 요구사항 변경 이력을 기록하는 파일입니다.

## 히스토리 로그

### [2026-06-04] v2.0.0 (형민 버전) 최초 릴리즈
- **폴더 분리**: 기존 루트 소스 코드와의 독립성 유지를 위해 `v형민` 폴더에 코드를 새로 작성하여 완전히 독립 구동하도록 구축.
- **포트 격리**: 기존 앱(8000 포트)과 실행 영역이 겹치지 않도록 **로컬 웹 서버 작동 포트를 8001**로 상향 격리.
- **아이콘 및 테마 차별화**: 
  - 스페로이드(Spheroid) 배양에 어울리는 **오렌지-옐로우 그라데이션 테마** 적용 (아이콘 색상 및 테마색 `#ffa000` 변경).
  - 다크 테마 기본 활성화.
- **신규 기능: Microwell Spheroid 계산기 탑재**:
  - 일정량의 세포 현탁액(Stock)을 이용해 Microwell Plate에 스페로이드를 형성하기 위한 세포 수 분주 용량 계산.
  - 입력값: 현재 현탁액 부피, 총 세포 수(지수 입력 방식), Well당 Microwell 개수, Microwell당 세포 수, 최종 분주 부피.
  - 출력값: Well당 필요 세포 수, 목표 총 필요 세포 수, 세포 현탁액 따낼 부피($\mu\text{L}$), 추가할 새 배지 부피($\mu\text{L}$).
- **제약 및 경고 조건 구현**:
  - 필요한 총 세포 수가 현재 가진 총 세포 수보다 많은 경우 경고 노출.
  - 목표 농도가 현재 원액 농도보다 높아 희석으로 제조할 수 없는 경우 경고 노출.

### [2026-06-04] v2.1.0 (스페로이드 계산기 고도화 및 UI 깨짐 수정)
- **Hemocytometer 연동**: 스페로이드 계산기 내에서 원액 농도 및 보유 세포량을 직접 계산할 수 있도록, 기존 과학적 지수 입력 방식 대신 **Hemocytometer 카운팅 수치(16칸 전체 cell 수 및 원액 부피) 입력** 방식으로 개선.
- **Plate 설정 및 요약 정보 추가**: Plate당 Well 수(기본 24)를 추가로 입력받아, 1 well당 필요 세포 수와 1 plate 전체 필요 세포 수를 실시간으로 한국어 숫자 단위(예: 24만 개, 576만 개)와 함께 요약해서 볼 수 있는 정보 박스 구현.
- **UI 깨짐 방지 개편**: 모바일 등 좁은 뷰포트에서 레이블 및 접미사들이 겹쳐 보이던 "목표 스페로이드 제조 설정" 박스의 가로 flex 배치를 **1열 세로 레이아웃**으로 레이아웃 전면 재개편하여 디자인 안정성 확보.

### [2026-06-04] v2.2.0 (수식 수정, 실시간 연산 보강, 공식 교정 및 자가 검증 강화)
- **수식 깨짐 해결**: HTML 표준 브라우저에서 깨지던 raw LaTeX 기호들을 완전히 제거하고, 가독성이 뛰어난 텍스트 및 HTML 아래첨자(`<sub>`) 구조로 개편하여 깨짐 현상 근본 차단.
- **PWA 강력 캐시 버스팅**: `sw.js` 캐시 버전을 `lab-calc-hm-v2.2.0`으로 올리고, `index.html`에 대해 **Network-First** 페치 전략을 적용하여 오프라인이 아닌 경우 항상 최신 UI를 즉시 불러오도록 구축.
- **서비스 워커 실시간 동기화**: `app.js`에서 신규 서비스 워커가 설치되었음을 감지하면 자동으로 브라우저 화면을 즉시 리로드(`window.location.reload()`)하는 갱신 핸들러 추가.
- **실시간 연산 즉시 반응**: 모든 인풋 요소에 `input` 이벤트 외에 `change` 이벤트를 이중 바인딩하여, 키 입력 및 스피너(화살표) 조정 시 연산이 실시간으로 이루어지도록 반응성 보강.
- **Hemocytometer 연산 공식 정상화**: 16칸 전체 cell 카운팅 수치 적용 시 `N * 2 * 10^4 cells/mL` 공식이 정상 실시간 연동되어 스페로이드 희석 수치를 출력하도록 점검 및 완료.
- **자가 검증 의무화 수칙 규정**: 작업 완료 후 로컬 8001 포트 서버에서 모든 시나리오별 수동 작동성 확인 절차를 명문화하는 수칙을 `soul.md`에 추가.

### [2026-06-04] v2.3.0 (스페로이드 인풋 라벨 변경 및 세포수 연산 공식 전면 개정)
- **인풋 기본값 변경**: 사용편의를 위해 "현재 세포 현탁액 정보"의 세포액 총 부피 기본값을 `5.0` mL에서 `1.0` mL로 하향 조정.
- **인풋 라벨 개정**: 목표 스페로이드 제조 설정 카드의 인풋 라벨을 `Plate당 Well 수` -> `Well 수`로, `최종 분주 준비 부피` -> `Well당 분주 부피` (기본값 `1.0` mL)로 개정.
- **스페로이드 연산 공식 전면 개정**:
  - `목표 총 필요 세포 수` = `Well 수` * `Well당 필요 세포 수` ($M_{well} \times N_{micro}$)
  - `목표 총 준비 부피` = `Well 수` * `Well당 분주 부피`
  - 레시피의 분주량 계산 공식을 위의 개정된 필요 세포 수 및 준비 부피 기준으로 전면 업데이트 완료.
- **sw.js 캐시 버스팅**: 캐시 버전을 `lab-calc-hm-v2.3.0`으로 인상하여 사용자의 캐시를 무효화하고 개정된 연산 공식 및 레이아웃을 즉시 반영.

### [2026-06-04] v2.5.0 (Spheroid 계산기 이전/현재 세포 현탁액 분리 및 현재 분주액 농도 계산 기능 추가)
- **이전/현재 현탁액 분리**:
  - 기존 "현재 세포 현탁액 정보"를 **"이전 세포 현탁액 정보"**로 변경하고, 하위에 신규 **"현재 세포 현탁액 정보"**를 분리 배치하여 다단계 희석 공정을 설계할 수 있게 UI 개정.
- **현재 분주액 농도 실시간 계산**:
  - 이전 원액 정보에서 연산된 `이전 전체 세포 수 (Total Cells)`를 기준으로 신규 입력받는 `현재 세포액 총 부피 (V_current_new)`로 나눈 **`현재 세포 분주액 농도`**를 자동으로 구하여 실시간 노출.
- **목표 스페로이드 제조 레시피 연동**:
  - 후속 스페로이드 분주 레시피 연산(따낼 부피 및 추가할 배지 부피)과 희석 경고 조건 검사 시 기준 농도를 이 개정된 현재 세포 분주액 농도로 연계 연동하도록 공식 전면 개편.
### [2026-06-04] v2.6.0 (Spheroid 계산기 기본값 최적화 및 UI 노출 정보 간소화)
- **기본값 조정**:
  - `이전 세포액 총 부피` 기본값을 기존 `1.0` mL에서 **`15.0` mL**로 상향 조정.
  - `현재 세포액 총 부피` 기본값은 **`1.0` mL**로 설정.
  - `Well 수` 기본값을 기존 `24` wells에서 **`1` well**로 하향 조정.
- **UI 노출 정보 간소화**:
  - "이전 세포 현탁액 정보" 카드 내부에서 중복되는 정보 혼선을 피하기 위해 **`이전 원액 농도 (Previous Density)`** 정보를 삭제하고 **`이전 원액 전체 세포 수 (Total Cells)`**만 노출하도록 개정.
- **sw.js 캐시 버스팅**: 캐시 버전을 `lab-calc-hm-v2.6.0`으로 인상하여 즉시 변경사항을 배포.
